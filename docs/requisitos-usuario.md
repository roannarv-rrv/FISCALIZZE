# Requisitos usuario

Base: relatório do segundo semestre, seção 2. Numeração original preservada. Classificação por inspeção estática do ZIP, não por teste de execução. Local = demonstrado no navegador; parcial = atendimento incompleto; futuro = não implementado; simulado = sem operação institucional.

| ID | Especificação original | Situação |
|---|---|---|
| RU01 | O cidadão deve poder criar uma conta e acessar o Fiscalizze por meio de autenticação. | Futuro |
| RU02 | O cidadão deve poder registrar uma denúncia ambiental informando o tipo, a descrição e a localização da ocorrência. | Local |
| RU03 | O cidadão deve poder complementar a denúncia com fotos, vídeos ou outros arquivos, quando disponíveis. | Parcial |
| RU04 | O cidadão deve poder consultar as denúncias registradas por ele. | Parcial |
| RU05 | O cidadão deve poder acompanhar o andamento de uma denúncia por meio de seus status. | Simulado |
| RU06 | O cidadão deve poder consultar ocorrências ambientais por categoria, localização, data ou status. | Parcial |
| RU07 | O cidadão deve receber informações sobre alterações no andamento de suas denúncias. | Futuro |
| RU08 | O responsável pela fiscalização deve poder consultar, analisar e encaminhar denúncias. | Futuro |
| RU09 | O responsável pela fiscalização deve poder atualizar o status e registrar observações sobre uma denúncia. | Simulado |
| RU10 | O administrador deve poder gerenciar usuários, categorias e registros de denúncias. | Futuro |
| RU11 | O administrador deve poder gerar relatórios sobre as denúncias cadastradas. | Futuro |
| RU12 | O sistema deve proteger os dados pessoais e controlar o acesso às informações conforme o perfil de cada usuário. | Futuro |
